2जाँच का नतीजा

3वेबसाइट पर डालें

1. डाउनलोड हुई ZIP खोलें — उसमें data फ़ोल्डर है।
2. उसे GitHub Desktop वाले pyqsetu-test फ़ोल्डर में Paste करें → Replace चुनें।
3. GitHub Desktop में Commit to main → Push origin।
4. 1–2 मिनट बाद test वाली वेबसाइट खोलकर देखें। सही लगे तो यही data फ़ोल्डर pyqsetu (live) में भी डालें।

पुराने विषय और टॉपिक अपने-आप सुरक्षित रहते हैं — सिर्फ़ Excel वाले टॉपिक नए बनते या बदलते हैं।
